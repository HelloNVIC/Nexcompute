# Spec Delta

## MODIFIED Requirements

### Requirement: 登录会话失效与失败提示

管理端后端 SHALL 对未认证请求（缺失、无效或过期的 token）统一返回 HTTP 401 与业务码 1003，MUST NOT 以 403 空响应体回应未认证请求。用户登录会话失效（HTTP 401 或业务码 1003）时，前端 SHALL 提示「登录已失效，请重新登录」并自动登出、跳转至登录界面；多个并发请求同时失效时 SHALL 仅提示一次并只执行一次跳转。已认证但无权限的请求（HTTP 403 权限拒绝）SHALL 仅提示具体无权限原因，不登出、不跳转。用户登录失败时，前端 SHALL 区分并提示具体错误类型（密码错误、账号不存在、账号被禁用等），不显示笼统的失败提示。

#### Scenario: 未认证请求统一返回 401 与业务码 1003
- **WHEN** 请求携带过期或无效 token（或未携带 token）访问受保护 API
- **THEN** 后端返回 HTTP 401
- **AND** 响应体业务码为 1003（令牌无效或已过期）

#### Scenario: 登录失效提示后跳转
- **WHEN** 用户在已登录状态下，某请求返回登录失效（HTTP 401 或业务码 1003）
- **THEN** 前端弹出「登录已失效，请重新登录」提示
- **AND** 自动登出并跳转至登录界面

#### Scenario: 并发失效仅提示一次
- **WHEN** 页面上多个并发请求同时返回登录失效
- **THEN** 前端仅弹出一次「登录已失效，请重新登录」提示
- **AND** 仅执行一次登出与跳转

#### Scenario: 权限拒绝不登出
- **WHEN** 已登录用户执行权限矩阵未授予的操作，后端返回 HTTP 403 权限拒绝
- **THEN** 前端提示具体无权限原因
- **AND** 不登出、不跳转登录页

#### Scenario: 登录失败密码错误
- **WHEN** 用户提交登录且密码错误
- **THEN** 前端提示密码错误

#### Scenario: 登录失败账号不存在
- **WHEN** 用户提交登录且账号不存在
- **THEN** 前端提示账号不存在

#### Scenario: 登录失败账号被禁用
- **WHEN** 用户提交登录且账号被禁用
- **THEN** 前端提示账号已被禁用
