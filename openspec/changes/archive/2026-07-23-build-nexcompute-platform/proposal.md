## Why

多台 Windows + GPU 主机散落在实验室中，算力无法统一调度、容器环境难以复用、学生与导师之间资源分配靠口头协调。Nexcompute（合算）要解决的是：**把分布式 GPU 主机统一为一个平台，按课题组角色分配机器、远程管理 Docker 容器、隔离用户存储、复用镜像**，让算力像水电一样按需取用。

## What Changes

这是一个从零开始的全新系统，分为管理端（单一实例）与受控端（多个物理实例）。

**管理端（SpringBoot + Vue + Ant Design + PostgreSQL + Redis + ApexCharts）**
- 三角色体系：管理员、导师、学生，权限以「角色 × 模块 × 操作（查看/编辑/删除）」矩阵配置
- 物理实例管理：受控端注册、编号、状态监控（CPU/GPU 占用与温度、内存、进程）、重启、息屏、PowerShell 远程执行（仅管理员，入审计）
- 容器全生命周期：表单创建（选镜像/存储池/资源限制/端口/SSH 密码）、启停重启删、SSH 连接信息与自定义应用连接信息生成；SSH 密码为容器级，创建时设置，可即时重置
- 存储池管理：按 `物理机编号-工号/学号-项目名` 命名，支持共享授权与跨机迁移
- 镜像管理：容器 commit 为镜像（tar 存储），归属用户，学生镜像导师可见、管理员全可见；管理员维护公共镜像库
- 资源分配：导师分配机器给学生（可共享），导师创建注册链接（UUID，指定次数与过期时间）供学生注册入组
- 工单系统：学生提交特需工单（五种类型），全部派给管理员处理回复关闭，学生通过未读消息查看结果
- 公告管理：管理员发布系统公告，所有用户查看
- 未读消息系统：所有用户拥有未读消息收件箱，包含自己容器/存储池的变动通知与工单变动通知
- 全操作审计日志入库

**受控端（Go exe + 可视化窗口）**
- 定时心跳保活 + 独立 WebSocket 命令通道（混合模式，方案 C）
- 本地调用 Docker API（不远程暴露），执行管理端派发的容器管理命令
- Docker 环境检查、控制端 IP 设置、系统状态显示
- 防止系统睡眠/休眠
- 存储池根目录设置（设后不可改，修改需本地管理员密码）
- 系统托盘常驻，管理员权限运行，开机自启，退出需本地管理员密码（管理端设置下发）
- 直连模式（穿透模式预留为「敬请期待」）
- 公共镜像启动时 + 定时自动同步
- 可靠大文件传输（断点续传），服务于存储池迁移、镜像 tar 分发、公共镜像同步

## Capabilities

### New Capabilities

- `agent-communication`: 受控端与管理端之间的心跳保活、WebSocket 命令通道、双向互信鉴权、命令执行与结果回传
- `physical-instance`: 物理实例注册与编号、状态监控采集、远程控制（重启/息屏/PowerShell）、连接模式（直连）
- `container-lifecycle`: 容器创建表单、启停重启删、容器级 SSH 密码注入、端口自动分配、连接信息生成
- `storage-pool`: 存储池创建与命名、共享授权、跨机迁移、容器挂载隔离
- `image-management`: 容器 commit 为镜像、tar 导出导入、归属与可见性、公共镜像库、自动同步
- `file-transfer`: 受控端 ↔ 管理端可断点续传的大文件传输，被迁移/镜像/公共库三场景复用
- `resource-allocation`: 导师分配机器、注册链接（UUID + 次数 + 过期）、课题组管理、多用户共享机器
- `access-control`: 三角色、权限矩阵（角色 × 模块 × 操作）、全操作审计日志
- `controlled-agent`: Go 受控端托盘 GUI、Docker 环境检查、防睡眠休眠、存储池根目录设置、本地管理员密码保护
- `ticket-system`: 学生特需工单提交（五种类型）、管理员处理回复关闭、工单可见性
- `monitoring`: 实时状态采集与 SSE 推送、历史数据存储（保留 30 日）、进程查看（按角色）、ApexCharts 展示
- `notifications`: 管理员公告管理、所有用户公告查看与未读消息收件箱（容器/存储池/工单变动通知）

（无--这是全新项目，openspec/specs/ 为空）

## Impact

**新增代码库**
- `management-backend/`：SpringBoot 后端（REST API、WS 端点、SSE 端点、调度、审计、通知）
- `management-frontend/`：Vue + Ant Design + ApexCharts 前端
- `controlled-agent/`：Go 受控端（托盘 GUI、心跳、WS、Docker 调用、文件传输）

**基础设施依赖**
- PostgreSQL（用户、课题组、物理实例、容器、存储池、镜像元数据、工单、公告、通知、审计、权限矩阵）
- Redis（消息队列、缓存、实时状态、端口分配锁）
- 文件存储（镜像 tar 包、公共镜像库、迁移中转数据）

**外部依赖**
- Docker Desktop（WSL2 后端，每台受控机）
- NVIDIA Container Toolkit（GPU 透传）

**安全面**
- PowerShell 远程执行（管理员限定 + 审计）
- Docker API 本地化（不暴露远程）
- SSH 容器级密码（创建时设置，可即时重置）
- 本地管理员密码（管理端设置下发，保护受控端退出与存储根目录修改）
- 全操作审计日志

**明确不做（Non-Goals）**
- 穿透模式（UI 显示「敬请期待」，本期不实现）
- GPU 多卡调度与 MIG 分片（一机一卡，GPU 显存软限制，容器共享 GPU 由用户自协调）
- 镜像层去重与版本回滚（tar 方案，接受冗余）
- 管理端高可用（单实例部署）
