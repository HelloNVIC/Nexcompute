# Nexcompute 端到端联调测试（任务 14.3-14.16）

本文档描述各端到端联调场景的步骤与预期结果。前置：启动 docker-compose（PostgreSQL + Redis）、管理端后端、管理端前端、受控端 exe。

---

## 14.3 受控端注册 -> 心跳 -> 本地管理员密码下发 -> 创建存储池 -> 创建容器(含SSH密码) -> SSH 连接

**步骤：**
1. 首次启动受控端，配置控制端 IP，心跳上报
2. 管理端自动注册物理实例（生成编号如 `01`），回传 token
3. 管理员在管理端设置受控端本地管理员密码，经 WS 下发
4. 学生在分配的物理实例上创建存储池（项目名 `bert-finetune`）
5. 学生创建容器（选镜像、存储池、设置 SSH 密码、资源限制）
6. 获取连接信息 `物理机IP:宿主SSH端口`
7. SSH 连接容器

**预期：**
- 受控端注册后显示编号 `01`
- 本地管理员密码下发成功，受控端保存
- 存储池目录 `01-工号-bert-finetune` 在受控端创建
- 容器创建成功，SSH 连接信息返回
- SSH 连接成功，使用设置的容器级密码

---

## 14.4 镜像 commit -> tar 上传 -> 跨机 load -> 创建容器

**步骤：**
1. 在物理机 A 的容器内安装软件后，执行 `docker commit`
2. 受控端 `docker save` 导出 tar，上传至管理端
3. 在物理机 B 上使用该镜像创建容器
4. 管理端将 tar 传输至物理机 B，`docker load` 导入
5. 创建容器

**预期：**
- tar 上传完成（断点续传正常）
- 物理机 B 导入镜像成功
- 跨机容器创建成功

---

## 14.5 存储池迁移全流程（含断点续传模拟、确认删除）

**步骤：**
1. 确保源存储池无运行容器
2. 发起迁移：物理机 A -> 物理机 B
3. 模拟传输中断（断网或重启受控端）
4. 恢复后继续传输（断点续传）
5. 传输完成，确认删除源池

**预期：**
- 前置检查通过
- 中断后恢复不重传已完成块
- 迁移完成后源池标记 MIGRATED
- 用户确认后源池数据删除

---

## 14.6 公共镜像库上传 -> 自动同步 -> 使用创建容器

**步骤：**
1. 管理员上传公共镜像 tar
2. 受控端定时同步拉取，`docker load`
3. 学生使用公共镜像创建容器

**预期：**
- 公共镜像出现在所有受控端
- 学生容器创建时直接使用已同步镜像，无需额外传输

## 14.7 权限矩阵鉴权（三角色 × 各模块 × 操作）

**步骤：**
1. 管理员配置权限矩阵：学生对存储池只勾选「查看」，取消「编辑」
2. 学生登录，尝试创建存储池

**预期：**
- 前端创建按钮不显示
- 直接调 API 返回 403 无权限
- 恢复权限后操作成功

**覆盖矩阵：** 管理员/导师/学生 × 物理实例/容器/镜像/存储池/工单/课题组/公告/监控

## 14.9 注册链接全流程（创建 -> 注册 -> 入组 -> 次数耗尽/过期/作废）

**步骤：**
1. 导师创建注册链接（次数 3，过期 30 天）
2. 学生 A 通过链接注册成功，入组，角色学生
3. 学生 B、C 注册成功（次数耗尽）
4. 学生 D 注册失败（次数耗尽）
5. 导师作废链接，新注册失败
6. 创建过短过期时间的链接，过期后注册失败

**预期：**
- 注册成功自动入组、角色学生
- 次数耗尽/过期/作废三种失效均拒绝注册

- 学生收到未读通知

## 14.12 受控端托盘常驻 + 退出密码保护 + 存储池根目录修改密码保护

**步骤：**
1. 关闭受控端窗口，验证缩到托盘不退出
2. 点击退出，输入错误密码 -> 拒绝
3. 输入正确密码 -> 退出
4. 尝试修改存储池根目录，输入错误密码 -> 拒绝
5. 输入正确密码 -> 修改成功

**预期：**
- 关窗口缩到托盘
- 退出需正确本地管理员密码
- 修改存储根目录需正确密码

## 14.13 公告发布（定向+定时）-> 目标用户未读消息 -> 查看 -> 已读 -> 历史回溯

**步骤：**
1. 管理员发布公告：定向某课题组 + 定时 5 分钟后
2. 5 分钟后自动发布
3. 课题组成员收到未读消息通知
4. 成员查看公告 -> 已读
5. 历史回溯查询已读公告

**预期：**
- 定时公告到点自动发布
- 仅定向用户收到通知
- 查看后标记已读
- 已读消息保留可回溯

**预期：**

## 14.15 容器级 SSH 密码重置即时生效验证

**步骤：**
1. 容器运行中，记录原 SSH 密码
2. 用户重置 SSH 密码
3. 立即用新密码 SSH 连接
4. 旧密码应连接失败

**预期：**
- 重置后新密码即时生效（docker exec chpasswd）
- 旧密码失效

## 14.16 存储池共享撤销（有运行容器时提示联系方式）

**步骤：**
1. 用户 A 将存储池共享给用户 B
2. 用户 B 创建容器挂载此池并运行
3. 用户 A 尝试撤销共享

**预期：**
- 系统提示「有 N 个运行容器使用此池」
- 展示卡住的容器列表
- 提供用户 B 的联系方式（姓名/邮箱/手机）
- 用户 B 停止容器后撤销成功
