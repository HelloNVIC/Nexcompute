
### 安装Docker
执行程序`Docker Desktop Installer.exe`

### 安装WSL环境

```shell
wsl --install # 安装WSL
wsl --set-default-version 2 # 切换到WSL2版本
wsl --install -d Ubuntu-26.04 # 安装Ubuntu 26.04发行版
wsl -l -v # 查看已安装的WSL列表及版本状态
wsl -d Ubuntu-26.04 #启动Ubuntu-26.04
```

### 检查显卡驱动
```shell
nvidia-smi # 确认宿主机显卡驱动与CUDA版本是否正常
```

### 离线安装NVIDIA Container Toolkit
先下载安装包并复制到Linux环境下
```shell
# 注意：需先将对应的deb包复制到WSL用户目录下，并严格按以下依赖顺序安装
sudo dpkg -i libnvidia-container1_1.19.1-1_amd64.deb # 安装基础库包（其他包依赖此包）
sudo dpkg -i libnvidia-container-tools_1.19.1-1_amd64.deb # 安装基础工具包
sudo dpkg -i nvidia-container-toolkit-base_1.19.1-1_amd64.deb # 安装基础组件包
sudo dpkg -i nvidia-container-toolkit_1.19.1-1_amd64.deb # 安装主要工具包
```

### 验证Toolkit安装并配置运行时
```shell
nvidia-ctk --version # 检查nvidia-container-toolkit是否安装成功
sudo nvidia-ctk runtime configure --runtime=docker # 配置Docker运行时以支持NVIDIA容器
```

### 修改Docker Engine配置
```json
// 在Docker Desktop的Docker Engine设置中添加以下JSON配置
{
  "runtimes": {
    "nvidia": {
      "path": "nvidia-container-runtime.exe", // 指定NVIDIA容器运行时路径
      "runtimeArgs": null // 运行时参数，默认为null
    }
  }
}
```

### 创建GPU容器并启动Jupyter
```shell
# 创建PyTorch容器，--gpus all为核心参数，将宿主机所有GPU透传给容器
docker run -it --rm --gpus all --name pytorch-26.06 -p 8888:8888 cmk5jct5sp432brntc-nvcr.xuanyuan.run/nvidia/pytorch:26.06-py3
docker exec -it pytorch-26.06 jupyter lab # 进入容器并启动Jupyter Lab服务
```


### 环境测试
```shell
# 在PowerShell中直接执行容器内Python测试命令，验证PyTorch与CUDA连通性
docker exec pytorch-26.06 python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA Available:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'None'); a = torch.randn(1024,1024, device='cuda'); b = torch.randn(1024,1024, device='cuda'); print('MatMul Shape:', torch.matmul(a,b).shape); print('✅ Test Passed!')"
```



### GPU压力测试
```shell
# 在后台运行容器内压力测试，用于检查显卡穿透是否满血
docker exec -d pytorch-26.06 python -c "import torch; device = 'cuda:0'; a = torch.randn(8192, 8192, device=device); b = torch.randn(8192, 8192, device=device); print('Stress test started...'); 
while True:
    torch.matmul(a, b) # 持续矩阵乘法
    torch.cuda.synchronize() # 强制同步确保真实负载"
```
